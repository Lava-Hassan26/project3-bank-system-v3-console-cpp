# Bank Management System - Extension 2 (v3)

A console-based **Bank Management System** written in **C++** (Phase 3 / Extension 2).

## Key Features

* ** Authentication & Login Screen:** Secure login interface with user session tracking.
* ** Bitwise Permissions Management:** Granular user access control (Show Clients, Add, Delete, Update, Find, Transactions, and Manage Users).
* ** Users Management Module:** Full CRUD operations for system users with Admin protection.
* ** Financial Transactions:** Deposit, Withdraw with balance validation, and Total Balances listing.
* ** Core Client Management:** Complete client management system backed by file persistence (`Clients.txt` & `Users.txt`).

## Tech Stack
* C++
* Structs & Enums (Bitwise Flags)
* Dynamic Vectors (`std::vector`)
* File Stream Handling (`fstream`)
* Input Validation Guards
